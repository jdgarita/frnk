## 🚀 Getting Started

1. **Clone the repo**

   ```bash
   git clone git@github.com:TweenerLabs/kmp-ship.git [YOUR_APP_NAME]
   ```

2. **Open the project**

   Open in **Android Studio** with the [Kotlin Multiplatform plugin](https://plugins.jetbrains.com/plugin/14936-kotlin-multiplatform) installed.

3. **Create a Firebase Project**

   You’ll need to create a Firebase project and connect both your Android and iOS apps. Check out [this guide](https://docs.kmpship.app/tutorials/create-firebase-project/).

4. **Run the project**

    * To run the Android app, start the `androidApp` run configuration.
    * To run the iOS app, start the `iosApp` run configuration.

5. **Read the documentation**

   Check out the full setup guide, architecture breakdown, and feature explanations here:

   👉 [https://docs.kmpship.app](https://docs.kmpship.app)
